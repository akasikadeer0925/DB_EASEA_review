# [Showcasing Dung Beetle research trends in East and Southeast Asia.]


## Short Summary of the Study
This repository contains the dataset and analysis code for our systematic review on dung beetle research trend in the East and Southeast Asia region. The provided Jupyter Notebook reproduces the analyses and figures presented in the manuscript.

## Code and Package Versions
To ensure computational reproducibility, the analysis was conducted using the following environment:
* **Operating System:** [Windows 11]
* **Software/Language Version:** Python 3.12.7
* **Git Fingerprint (Commit Hash):** [e.g., a1b2c3d4]

**Dependencies (Python Packages):**
* `matplotlib` 3.12.7 (Hunter, 2007)
* `seaborn` 0.13.2 (Waskom, 2021)
* `numpy` 1.26.4 (Harris et al., 2020)
* `pandas` 2.2.2 (McKinney, 2010)
* `geopandas` 1.1.3 (Jordahl et al., 2021)
* `networkx` 3.3 (Hagberg et al., 2008)
